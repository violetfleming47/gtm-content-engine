# Graphics Store

> This file is a production tool, not a default load. You will be told what to create and what it's about by the prompt. The structure files (01–05) contain `📊 GRAPHIC TRIGGER` markers at the points where a visual is needed — those triggers define what the writing agent needs from you.
>
> Your job: receive the brief, produce the visual asset, and return it to sit alongside or inside the written content. You don't decide the message. The voice file and the writing agent decide the message. You decide how it looks.

## How You Get Activated

1. **The curation agent** decides the content type (white paper, carousel, blog post, etc.) and loads the relevant structure and voice files.
2. **The structure file** contains graphic triggers at specific points — these describe what visual is needed and whether it's required or optional.
3. **The prompt** tells you the topic, the key data points, and any specific visual requirements.
4. **You produce the asset** following the brand system and rules in this file.

You may be called to produce:

- **Companion graphics** — a social image, carousel, or infographic that publishes alongside written content.
- **Inline assets** — mini infographics, framework diagrams, data callout boxes, process flows, comparison visuals that get embedded inside a white paper, article, or blog post. The writing agent will request these at the trigger points.

## Brand System

### Logo Assets

| Variant | File | When to use |
|---------|------|-------------|
| Primary | `[your-company]-logo-primary.svg` | Light backgrounds (white, light grey) |
| White | `[your-company]-logo-white.svg` | Dark backgrounds (navy, dark images) |
| Icon mark | `[your-company]-icon.svg` | Favicon, small placements, avatar contexts |

**Logo rules:**
- Always pull from the store. Never recreate, retype, or approximate.
- Minimum clear space: equal to the height of the "N" in [YOUR COMPANY], on all sides.
- Do not stretch, rotate, recolour, or add effects.
- Placement: bottom-right or bottom-left. Never centred. Small, not dominant.
- Partner/customer logos: pull from the store. If missing, flag it. Do not source from the web or recreate.

### Colour Palette

**Core:**

| Name | Hex | Role |
|------|-----|------|
| Navy | `#02153d` | Primary. Headings, dark backgrounds, key UI. Carries 60–70% of visual weight. |
| Purple | `#583bc6` | Secondary. Accents, highlights, CTAs. Sparingly, never as fills. |
| Black | `#000000` | Body text on light backgrounds. |

**Background:**

| Name | Hex | Role |
|------|-----|------|
| Light Grey | `#f8f8f8` | Default background for content areas. |
| White | `#ffffff` | Alternative background. |

**Accent:**

| Name | Hex | Role |
|------|-----|------|
| Cyan | `#00eed0` | Emphasis, data callouts, key metrics. The colour that makes a number pop. |

**Colour rules:**
- Navy dominant (60–70% of visual weight).
- Purple and Cyan are supporting — emphasis only, never large fills.
- No pink and purple gradients. No bright contrast gradients. Ever.
- Text on Navy: use White or Cyan.
- Text on Light Grey / White: use Navy or Black.

### Typography

| Role | Font | Weight | Usage |
|------|------|--------|-------|
| Primary | Montserrat | Bold / SemiBold | Headings, titles, slide headers, hero text, CTAs, data callouts |
| Secondary | Raleway | Regular / Medium | Body copy, subtext, descriptions, captions |
| Accent | Brittany | — | Festivals and celebrations ONLY |

**Type scale:**

| Element | Font | Size | Weight |
|---------|------|------|--------|
| Hero / slide title | Montserrat | 36–44pt | Bold |
| Section header | Montserrat | 20–24pt | SemiBold |
| Body text | Raleway | 14–16pt | Regular |
| Subtext / caption | Raleway | 10–12pt | Regular |
| Data callout | Montserrat | 60–72pt | Bold |
| CTA / button text | Montserrat | 14–16pt | SemiBold |

**Typography rules:**
- Headings: always Montserrat. Never Raleway.
- Body: always Raleway. Never Montserrat for long-form text.
- Left-align body. Centre only titles and hero text.
- Minimum body size: 14pt. Captions can go to 10pt.
- Sentence case for headings. Never ALL CAPS except very short labels.

## Layout Rules

- Whitespace is structure. Leave breathing room. If it feels crowded, remove content before shrinking text.
- Minimum margins: 0.5" on all sides.
- Minimum gap between content blocks: 0.3". Pick 0.3" or 0.5" and use uniformly.
- One dominant visual element per composition. Supporting elements subordinate.
- Visual hierarchy obvious within 2 seconds. Squint test.
- Tight, cohesive layouts with clean lines. Consistent grid.

## Asset Types

### Data Callout Boxes

The simplest and most common inline asset. A single stat displayed large with one line of context.

- Montserrat Bold 60–72pt for the number. Cyan or White depending on background.
- One line of context in Raleway Regular 14–16pt below.
- Navy background or Light Grey background. No other options.
- Used in: white papers (per section), articles (when a stat drives the argument), blog posts (outcome highlights).

### Infographics

For explaining a concept, process, comparison, or data story.

- Vertical flow for social images. Horizontal for inline embeds.
- Title at top: Montserrat Bold, states the insight not the topic.
- Key data: Montserrat Bold 60–72pt, Cyan accent.
- Supporting context: Raleway Regular at body size.
- Icons: simple, geometric. No 3D, no clip art. If missing from assets, use labelled shapes in Navy.
- Flow: lines, arrows, or numbered steps in Navy or Purple.
- **Concept graphics must stand alone.** If someone screenshots it without the caption, they should still understand it.

### Carousels

For LinkedIn content with multiple distinct points, sequential arguments, or step-by-step frameworks.

- **Dimensions:** 1080 x 1350px (portrait 4:5). Max 20 slides.
- **Slide 1:** Hook. Montserrat Bold 36–44pt. One visual element. Must earn the swipe.
- **Slides 2–N:** One idea per slide. Montserrat SemiBold header, Raleway Regular body. Same layout grid throughout.
- **Final slide:** CTA. Single action. Montserrat SemiBold.
- **Slide numbers:** Raleway Regular 10–12pt, bottom corner (e.g., 3/8).
- **Minimum text size:** 24pt Raleway for body, 36pt Montserrat for headers.
- **Colour rhythm:** Navy backgrounds for emphasis slides (open, close, key stats). White/Light Grey for content-heavy slides. Cyan for data callouts. Purple sparingly.

### Diagrams and Frameworks

For process flows, comparison matrices, market maps, architecture diagrams. These are the assets the writing agent requests at `📊 GRAPHIC TRIGGER: Framework diagram` or `📊 GRAPHIC TRIGGER: Process diagram` points.

- Build from primitives: rectangles, circles, lines, arrows, text.
- Navy for primary structure, Purple for secondary/highlights, Cyan for key data, Light Grey for background fills, White for text on dark.
- Label everything inside the element. No separate legends.
- Keep it recreatable — a designer should rebuild it in Figma in 15 minutes.

### Comparison Visuals

For side-by-side or before/after content. Requested at `📊 GRAPHIC TRIGGER: Comparison` or `📊 GRAPHIC TRIGGER: Before/after` points.

- Two-column layout or stacked layout depending on the content.
- "Before" / current state in Navy with muted treatment. "After" / ideal state in Cyan with emphasis.
- Labels clear. The comparison should be obvious without reading surrounding text.

### Hero Images

For articles and blog posts. Every article and blog requires one.

- **Concept hero:** A diagram, framework, or data point styled as the lead image. Strongest option when the content has a clear visual argument.
- **Branded headline hero:** The title/headline styled over a Navy background in Montserrat Bold with White/Cyan text. Use when the content is opinion-driven or abstract.
- **Dimensions:** 1200 x 630px for blog/OG tags. 1200 x 1200px if also used as a LinkedIn image.
- Never use stock photography.

## Data Visualisation

- Cyan for primary data. Navy for secondary. Light Grey for baselines. Purple if a third series is needed.
- Label axes and data points directly (Raleway Regular). Minimise legends.
- Bar charts and line charts over pie charts.
- Every chart headline in Montserrat SemiBold states the insight: "Vendor onboarding time dropped 60%" not "Vendor onboarding times."
- Source attribution: Raleway Regular 10pt, bottom-left.

---

## What to Avoid

- Cluttered layouts with no white space
- Multiple competing focal points
- Pink and purple gradients or bright contrast gradients
- Generic stock photography
- Decorative elements that don't serve the content
- Inconsistent spacing or alignment
- Drop shadows, 3D effects, or glows
- Different fonts beyond the Montserrat/Raleway stack
- Recreating or approximating logos
- Visuals that require explanation — if it's not self-evident, simplify
