# [YOUR COMPANY] Brand Framework

## Purpose

This framework is the single source of truth for [YOUR COMPANY]'s visual identity. Any agent producing visual content — carousels, infographics, one-pagers, slide decks, social graphics — reads this before generating output.

---

## Logo

### Assets

- Primary logo: `[your-company]-logo-primary.svg`
- Logo on dark: `[your-company]-logo-white.svg`
- Favicon / icon mark: `[your-company]-icon.svg`

### Usage Rules

- Always use the provided logo files — never recreate, retype, or approximate the logo
- Minimum clear space around the logo: equal to the height of the "N" in [YOUR COMPANY] on all sides
- Do not stretch, rotate, recolour, or add effects to the logo
- On dark backgrounds, use the white variant
- On light backgrounds, use the primary variant

## Colour Palette

### Core Colours

| Name | Hex | Usage |
|------|-----|-------|
| Navy | `#02153d` | Primary brand colour. Headings, key UI elements, dark backgrounds |
| Purple | `#583bc6` | Secondary brand colour. Accents, highlights, CTAs |
| Black | `#000000` | Body text on light backgrounds |

### Background & Neutral

| Name | Hex | Usage |
|------|-----|-------|
| Light Grey | `#f8f8f8` | Default background for content areas |
| White | `#ffffff` | Alternative background when not using light grey |

### Accent

| Name | Hex | Usage |
|------|-----|-------|
| Cyan | `#00eed0` | Accent colour for emphasis, data callouts, key metrics. Subject to future update |

### Colour Rules

- No pink and purple gradients
- No bright contrast gradients
- Navy is the dominant colour — it should carry 60–70% of visual weight in any composition
- Purple and Cyan are supporting — used sparingly for emphasis, not as fills
- When layering text over Navy backgrounds, use White or Cyan for contrast
- When layering text over Light Grey or White backgrounds, use Navy or Black

## Typography

### Font Stack

| Role | Font | Weight | Usage |
|------|------|--------|-------|
| Primary | Montserrat | Bold / SemiBold | Headings, titles, slide headers, hero text |
| Secondary | Raleway | Regular / Medium | Subtext, body copy, descriptions, captions |
| Accent | Brittany | — | Festivals and celebrations content only |

### Type Scale

| Element | Font | Size | Weight |
|---------|------|------|--------|
| Hero / slide title | Montserrat | 36–44pt | Bold |
| Section header | Montserrat | 20–24pt | SemiBold |
| Body text | Raleway | 14–16pt | Regular |
| Subtext / caption | Raleway | 10–12pt | Regular |
| Data callout (large stat) | Montserrat | 60–72pt | Bold |
| CTA / button text | Montserrat | 14–16pt | SemiBold |

### Typography Rules

- Headings are always Montserrat — never use Raleway for headings
- Body copy is always Raleway — never use Montserrat for long-form body text
- Brittany is restricted to festivals and celebrations only — never use it for product, thought leadership, or corporate content
- Left-align body text — centre only titles and hero text
- Minimum body text size is 14pt — nothing smaller except captions at 10pt

## Design Principles

### Overall Style

- Clean, minimalist aesthetic
- White space-rich layouts — leave breathing room, don't fill every inch
- Straightforward, impactful text (Apple-inspired clarity)
- Every visual needs a clear hierarchy: one dominant element, supporting elements subordinate

### Visual Tone

- Trustworthy and credible
- Consistent graphic style across all outputs
- Visually appealing and professional
- Confident without being flashy — let the content lead

### Layout Rules

- Minimum margins: 0.5" on all sides
- Minimum gap between content blocks: 0.3"
- One dominant visual element per composition — don't compete for attention
- Consistent spacing throughout — pick 0.3" or 0.5" gaps and use them uniformly
- Tight, cohesive layouts with clean lines

### What to Avoid

- Cluttered layouts with no white space
- Multiple competing focal points
- Pink and purple gradients
- Bright contrast gradients
- Generic stock photography
- Decorative elements that don't serve the content
- Inconsistent spacing or alignment
- Text-only compositions with no visual element
